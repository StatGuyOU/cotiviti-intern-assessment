# Submission checklist

1. Open `report/Penghua_Wang_Report.docx` in Word. Read it once, adjust any wording,
   confirm it is two pages of text plus the references page.
2. Open `slides/Penghua_Wang_Slides.pptx`. Check every slide and the speaker notes.
3. From `poc/`: run `python claims_radar.py` and `python -m pytest -q tests`.
4. Record the video (rehearse to 4:30-4:40); save as
   `video/Penghua_Wang_Presentation.mp4`, under 100 MB.
5. In `README.md`, delete the "(recorded last)" note on the video row once the file exists.
6. Confirm `Penghua_Wang_Resume.pdf` is the version you want on file.
7. Create a public GitHub repository (for example `cotiviti-intern-assessment`),
   push this folder, then clone it into a fresh directory and confirm the MP4 plays
   from the GitHub file page and `python claims_radar.py` runs after
   `pip install -r poc/requirements.txt`.
8. Done: the last slide, the script, and the README point to
   `github.com/StatGuyOU/cotiviti-intern-assessment`.
9. Paste the repository URL into the Microsoft Form linked in the instructions PDF.
